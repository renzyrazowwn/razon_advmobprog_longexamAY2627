## CTADMOBPL Advanced Mobile Programming
For this activity, I learned how the models, services, and screens work together to make the application function properly. The models define and organize the data, while the services handle communication with the DummyJSON API and convert the responses into usable data. The screens then use these services to retrieve and display the information to the user. This creates a simple flow where screens request data from services, and services use models to structure that data. Overall, understanding this interaction helped us see how separating responsibilities makes the application more organized, manageable, and easier to improve.
